# Навык: Аналитика рынка

## Цель
Провести анализ выбранного рыночного сегмента, используя открытые источники, и подготовить структурированный отчёт с количественными данными, визуализациями и практическими рекомендациями.

## Обязательные этапы

### 1. Определение границ анализа
Запроси у пользователя:
- **Сегмент** (например, «облачные хранилища для бизнеса»)
- **География** (Россия, СНГ, мир)
- **Период** (последние 3–5 лет + прогноз на 2–3 года)
- **Ключевые показатели** (объём рынка, CAGR, доли игроков, цены, технологические тренды)

### 2. Сбор текстовых данных (ddgs_search_web)
Выполни поиск по следующим запросам (адаптируй под сегмент):

| № | Запрос (пример) |
|---|----------------|
| 1 | `обзор рынка [сегмент] [география] 2025` |
| 2 | `объем рынка [сегмент] [география] млрд руб` |
| 3 | `ключевые игроки рынка [сегмент] [география]` |
| 4 | `доли рынка [сегмент] [география] проценты` |
| 5 | `цены на [сегмент] динамика` |
| 6 | `тренды [сегмент] [география] 2025` |
| 7 | `прогноз рынка [сегмент] [география] до 2030` |
| 8 | `технологические инновации [сегмент]` |

Для каждого запроса извлеки:
- Цифровые данные (объём, темпы роста)
- Названия компаний, их доли
- Ценовые диапазоны
- Тренды (например, импортозамещение, AI, автоматизация)

### 3. Сбор изображений (ddgs_search_images)
Найди готовые визуализации:
- `график роста рынка [сегмент] [география]`
- `доли игроков [сегмент] диаграмма`
- `инфографика рынок [сегмент]`

Ссылки на изображения включи в отчёт как дополнительные материалы.

### 4. Структурирование данных в CSV
Создай CSV-файл `market_data_[сегмент].csv` с колонками:
- `Год`
- `Объём_рынка_млрд_руб`
- `Темп_роста_%`
- (при необходимости) `Цена_средняя`, `Количество_игроков`

Пример заполнения на основе найденных данных (если точные цифры не найдены – используй оценки из авторитетных источников с пометкой «оценка»).

### 5. Построение графиков (опционально)
Для построения графиков предпочтительно использовать matplotlib. mcp инструменты и вставлять ссылки на получившиеся изображения в Markdown разметке
Создай файл `analytics_report_[сегмент]_[дата].md` через `fs_write_text` со следующей структурой:

```markdown
# Аналитический отчёт по рынку «[сегмент]»
**География:** [география]  
**Период анализа:** [годы]  

## 1. Резюме
- Ключевые цифры и выводы (2–3 абзаца).

## 2. Объём и динамика рынка
- Таблица с объёмами по годам.
- График (ссылка или описание).
- Темпы роста (CAGR).

## 3. Конкурентная среда
- Топ-5 игроков с долями (таблица).
- Краткое описание стратегий лидеров.

## 4. Ценовой анализ
- Диапазоны цен.
- Тренды (рост/снижение).

## 5. Технологические тренды и инновации
- 3–5 ключевых трендов.
- Влияние на закупки.

## 6. Прогноз развития
- Ожидаемый объём через 2–3 года.
- Новые возможности и риски.

## 7. Рекомендации для закупок
- На каких поставщиков обратить внимание.
- Какие технологии предпочтительны.
- Рекомендуемая стратегия (например, консолидация закупок, тендеры).

## 8. Источники
- Ссылки на использованные статьи, отчёты, изображения.
7. Предоставление результата пользователю
Отправь пользователю резюме (основные выводы) и путь к файлу с полным отчётом.
```

Спроси, нужны ли дополнительные уточнения или визуализации.


### Важные требования
Достоверность: Если данные противоречивы – указывай диапазон и ссылайся на источник.
Актуальность: Используй отчёты не старше 3 лет.
Полнота: Заполняй все разделы отчёта. При отсутствии данных – пиши «нет открытых данных».
Язык: Отчёт на русском, профессиональный стиль.
Практическая ценность: Рекомендации должны быть конкретными и полезными для специалиста по закупкам.
